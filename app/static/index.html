Avvia NeuroStudy dal progetto completo

Questa applicazione richiede il server Python. Aprire direttamente il file index.html non avvia il servizio.

  1. Scarica ed estrai l’intero progetto dal repository, non solo questo file.
  2. Su Windows, nella cartella estratta fai doppio clic su Avvia NeuroStudy.cmd.
  3. Il programma prepara le dipendenze e apre l’app nel browser. Mantieni aperta la finestra di avvio.

Serve Python 3.12 o successivo. Le istruzioni complete sono nel file README.md del progetto.

Su Android non aprire questo file: collega il telefono alla stessa rete Wi-Fi del PC e apri nel browser l’indirizzo mostrato da Avvia NeuroStudy WiFi.cmd, dopo aver configurato la password sul PC.
